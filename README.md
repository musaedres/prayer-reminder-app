# 📱 تطبيق تذكير الصلاة

## 🌟 حول التطبيق

تطبيق احترافي وذكي لتذكير أوقات الصلاة المفروضة مع واجهة مستخدم جميلة وسهلة الاستخدام.

### ✨ المميزات الرئيسية

- 🕌 **تحديد أوقات الصلاة الدقيقة** بناءً على الموقع الجغرافي
- 🔔 **تنبيهات ذكية** قبل كل صلاة
- 🌙 **دعم التقويم الهجري** والميلادي
- 🎨 **واجهة مستخدم حديثة وجذابة**
- 🌍 **دعم اللغة العربية** بالكامل
- 📊 **إحصائيات شاملة** للصلوات المؤداة
- 🌗 **وضع مظلم وفاتح**
- 📍 **تحديد موقع تلقائي** باستخدام GPS
- 🔐 **خصوصية عالية** - لا توجد بيانات خارجية

## 🚀 البدء السريع

### المتطلبات
- Node.js 14 أو أعلى
- npm أو yarn

### التثبيت

```bash
git clone https://github.com/musaedres/prayer-reminder-app.git
cd prayer-reminder-app
npm install
```

### التشغيل

```bash
npm run تطوير
```

سيتم فتح التطبيق في المتصفح على `http://localhost:3000`

### البنية المعمارية
